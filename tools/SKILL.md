# ⚽ 上半场大小球分析技能（V38 增强版）

## 系统架构

```
12:00 每日分析
  ├── ① verify-v38-auto.js  验证昨天推荐
  │    └── 输出命中率统计 + 联赛追踪 → 报告
  ├── ② jiebao-scraper-v38.js 采集今日比赛
  │    └── 每场采集: H2H + 盘口 + 团队数据(入球分布/时间/大小球)
  └── ③ report-v38.js 标准化报告 → 微信推送
```

## 执行脚本
```bash
cd /Users/chenguoqing/.openclaw/workspace/tools
node jiebao-scraper-v38.js          # 采集分析
node report-v38.js                   # 生成报告
node verify-v38-auto.js              # 自动验证
```

## 输出文件
- 推荐清单: `/tmp/jiebao-analysis-v38.json`
- 预测存档: `data/验证存档/v38/predictions.json`
- 统计数据: `data/验证存档/v38/stats.json`

## V38 完整规则

### 硬性门槛（全满足才推）
| 条件 | 要求 |
|:---|:---:|
| H2H场数 | ≥4 |
| 上半场进球率 | ≥80% |
| HT 0-0场数 | ≤2 |
| 半场盘口 | 必须存在 |
| 联赛 | 仅29个主流顶级联赛 |

### 买入时机
| 盘口 | 买入 | 说明 |
|:---:|:----:|------|
| ≤1.25 | ✅直接投 | 无条件直接入 |
| ≥1.5 | ✅看数据决定 | H2H够硬+团队场均高→接受 |
| ⬆️升盘 | ✅尽快买入 | 机构看好 |
| ⬇️降盘至≤0.75 | ⚠️谨慎 | 盘口过低 |
| ≥1.5且数据弱 | ❌跳过 | 不值 |

### 增强数据（新）
1. **入球分布** — 本赛季两队HT场均进球
2. **入球时间** — HT进球集中时段(31-45'占比)
3. **大小球率** — 球队大球倾向
4. **以上数据用于≥1.5盘口决策**

### 联赛范围（29个）
五大 + 荷葡比苏土俄挪瑞典丹奥瑞 + 英冠德乙西乙意乙法乙 + 日韩澳 + 美墨巴阿
