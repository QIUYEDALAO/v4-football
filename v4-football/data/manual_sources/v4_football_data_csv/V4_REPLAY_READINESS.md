Assess whether football-data.co.uk CSV files can support V4 price-aware replay — i.e., backtesting betting strategies that incorporate opening odds, closing odds, Asian handicap, and over/under markets alongside match results and basic statistics.

## Criteria for V4 Replay Readiness

A league-season is **READY** if it has:
1. ✅ Match results: Date, HomeTeam, AwayTeam, FTHG, FTAG, FTR
2. ✅ 1X2 odds (at least Bet365): B365H, B365D, B365A
3. ✅ Opening odds (Pinnacle): PSH, PSD, PSA
4. ✅ Closing odds (Pinnacle C): PSCH, PSCD, PSCA
5. ✅ Over/Under 2.5 (Bet365): B365>2.5, B365<2.5
6. ✅ OR Asian Handicap (Bet365): B365AHH, B365AHA, B365AH
7. ✅ Basic match stats: HS, AS, HST, AST, HC, AC

A league-season is **PARTIAL** if results + some odds are present but some key markets are missing.
A league-season is **NOT_READY** if odds are absent or severely limited.
