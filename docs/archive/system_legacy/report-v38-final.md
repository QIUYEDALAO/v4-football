### 核心评分逻辑
1. 硬性门槛：H2H≥4场 + 进球率≥80% + 0-0≤2场 + 有盘口
2. 分级推荐：100%→🔥🔥强烈推荐 | 80-89%→✅推荐（需场均满足条件）
3. 加分/扣分：连胜趋势+1、盘口低估+0.5~1、团队数据+0.5、进球集中+0.3、连冷-1
4. 买入时机：盘口≤1.25直接投，1.5+看数据，降盘门槛降低

## 第二部分：专家共识（三位专家一致同意）

### ✅ 共识一：80-89%档必须加近期状态过滤

**问题：** 80-89%档命中率仅52.2%，原因是「历史好但当前状态差」的比赛混入推荐。

**两个方案，我选择A：**

**方案A（我赞成）：共振系数过滤**
- 公式：`近3场HT进球率 / H2H进球率`
- ≥1.0（近期更猛）→ 加分+1
- 0.6~0.99 → 正常保留
- <0.6（近期断崖下滑）→ 直接跳过

**方案B（专家1提的）：** 单纯近3场HT<30%跳过

**我选A的理由：** 方案B太粗暴会误伤「刚好近期遇强敌0-0但本场遇弱旅」的情况。共振系数能精确量化「近期 vs 历史」的偏离程度，比固定阈值更科学。

### ✅ 共识二：水位验证区分真降盘 vs 诱盘

**问题：** 当前只看盘口数值变化，不管水位。「升水降盘」是诱盘，「降水降盘」才是真信号。

**改动：** `extractCrownOdds()` 同时提取水位：
- 降水降盘 → 买入信号 ✅
- 升水降盘 → 拉黑跳过 ❌
- 0.75盘口 + 高水(>1.90) → 降级，半场0.75盘是刺客

### ✅ 共识三：近2次H2H交锋验证

**问题：** 4场H2H可能跨度8-10年，10年前的战术和人员对现在毫无参考价值。

**改动：** 如果最近2次交锋半场0-0，近期战术已转保守，直接跳过。

### ✅ 共识四：联赛基准线（零API方案）

**问题：** 当前团队数据`parseOddsStats`已提取大小球率但未使用。

**改动：** 用捷报自带联赛半场大球率作为锚点：
- 联赛HT大球率<45%（沉闷联赛）→ 80-89%档跳过，100%档降级
- 联赛HT大球率>55%（疯狂联赛）→ 80-89%档稳定推荐，100%档🔥🔥

## 第五部分：世界杯让球盘准备（为什么现在开始练）

### 当前局限
V38只分析半场大小球。但世界杯要打让球盘AH。

### 让球盘与半场大小球的差异
| 维度 | 半场大小球 | 让球盘AH |
|:----|:----------|:---------|
| 有效命中率 | ≥80%才盈利 | **≥55%即可盈利**（均赔1.85） |
| 核心依赖 | H2H进球率（历史） | 近期状态+实力差（当前） |
| H2H价值 | 高（联赛战术延续） | **低**（国家队4年一轮换） |
| 市场效率 | 局部边缘 | 全球聪明钱洪流 |

### 过渡方案
1. 当前在联赛让球盘上跑数据验证，不真投，只记录
2. 积累让球盘特征提取→评分→验证的完整链路
3. 世界杯前总结出：哪些特征有效、哪些联赛可参考、什么信号是假信号

### 世界杯规则预设
```
小组赛第1轮: 深盘(≥1.25)不追，强队慢热
小组赛第3轮: 无战意比赛一律降级
淘汰赛: 倾向小球，让球盘极度谨慎
中立场+跨洲: 实力差权重打折
夺冠赔率倒数: 替代ELO做实力差基准
```
