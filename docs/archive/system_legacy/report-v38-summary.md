## 一、项目背景

**目标**：每日从捷报比分网（live.nowscore.com）采集比赛数据，分析半场大小球和全场让球盘，输出可执行的投注推荐。

**投注者需求**：
- 日常跑**半场大小球**（历史H2H进球率≥80%）
- 为**2026世界杯**做准备 → 现在要开始验证**让球盘（AH）**，用联赛数据训练模型
- 本金2000，单注100-300

**核心策略假设**：历史交锋上半场有进球的比赛，本场上半场也容易有进球。

**已验证数据**（4/27-5/1，46场）：
- 100%进球率档：89.5%命中率 🔥
- 80-89%进球率档：52.2%命中率 ⚠️
- 整体：69.6%

## 四、分析逻辑（smartRecommend）

### 4.1 硬性门槛（不满足直接过滤）

```
H2H场次 <  h2hMinCount(4)  → 跳过
进球率 <  h2hMinRate(80%)  → 跳过
0-0场次 > h2hMaxZeroZero(2) → 跳过
无半场大小球盘口 → 跳过
```

### 4.2 分级推荐（通过门槛后的评分）

```
100%进球率:
  H2H≥6 + 场均≥1.2 → 🔥🔥强烈推荐
  H2H≥6 + 场均<1.2 → ✅推荐
  H2H=4-5 → ⚡样本小

80-89%进球率:
  场均≥1.8 → ✅推荐
  H2H≥8 + 场均≥1.5 → ✅推荐
  其他 → ❌跳过
```

### 4.3 加分/扣分（调整等级）

| 条件 | 调整 |
|:----|:----:|
| 两队近期连胜趋势 🔥 | +1分 |
| 初盘低估（历史场均 > 盘口） | +0.5~1分 |
| 团队HT场均 ≥ 0.8 | +0.5分 |
| 进球集中31-45' ≥ 50% | +0.3分 |
| 团队数据弱 | -0.3分 |
| 连冷趋势 ❌ | -1分 |
| 总分≥1.5 → 🔥🔥升级 | 反之降级 |

### 4.4 买入时机

```
盘口 ≤ 1.25 → ✅直接投
盘口 ≥ 1.5  → 看数据: 100%+H2H≥6+场均高→接受,否则跳过
降盘信号 → ✅直接投（门槛降低）
升盘信号 → ⏳观望（数据硬才接受）
1-10分钟两队进球率都<10% → ⏳等10分钟降盘再入
```

## 六、世界杯让球盘准备计划

### 6.1 现状

当前V38只分析**半场大小球**（大小球盘口），不碰让球盘。要让球盘能跑，需要：

1. **采集层**：从Crown全指数区同时提取「全场让球盘」数据（当前只取了半场大小球）
2. **策略层**：新建一套让球盘评分逻辑（不能用H2H进球率，要用近期状态+实力差）
3. **验证层**：让球盘命中率55-58%就够盈利（半场大小球需要80%+）

### 6.2 让球盘与半场大小球的关键差异

| 维度 | 半场大小球（当前） | 让球盘AH（世界杯目标） |
|:----|:-----------------|:-------------------|
| 有效命中率 | ≥80%才能盈利 | **≥55%即可盈利**（均赔1.85） |
| 核心指标 | H2H进球率（历史） | **近期状态+实力差**（当前） |
| H2H价值 | 高（联赛战术延续） | **低**（国家队4年一变） |
| 盘口深度 | 流动性差，机构定价薄 | **流动性强，机构精算严密** |
| 市场效率 | 有局部边缘 | 高度有效市场 |
| 世界杯特殊性 | 节奏固定可套用 | **小组赛慢热/淘汰赛谨慎/国旗效应** |

### 6.3 需要增加的让球盘特征

| 特征 | 提取来源 | 说明 |
|:----|:---------|:-----|
| 全场让球初盘 | Crown全指数区「全场」行 `parts[5]` | 开多少 |
| 全场让球即时盘 | 同上，对比初盘 | 盘口移动方向 |
| 初盘上盘水位 | `parts[4]` | 初始态度 |
| 即时上盘水位 | 同上，对比初盘 | 资金流向 |
| 近期积分 | 近期戰績段 | 状态量化 |
| 近6场进球/失球 | 近期戰績段 | 攻防能力 |
| 联赛排名差 | 联赛积分表 | 实力差 |
| 盘口变化速率 | 初盘vs当前 | 急变=诱盘信号 |
| 休息天数 | 赛程日期 | 体能影响 |
| 中立场/杯赛标记 | 赛事名称关键词 | 国家队赛事开关 |

### 6.4 世界杯让球盘规则预设

```
小组赛第1轮: 深盘(≥1.25) → 不追，观察
小组赛第2/3轮: 出线战 → 看近期状态
淘汰赛: 任何对阵 → 倾向小球，让球盘谨慎
中立场+跨洲: 实力差权重打折
公众热度高(传统强队) → 下盘价值
```
