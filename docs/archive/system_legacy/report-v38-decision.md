### 1.3 评分逻辑（smartRecommend，已配置驱动）

**硬性门槛（不满足直接过滤）：**
- H2H场次 < 4 → 跳过（CFG.filters.h2hMinCount）
- 进球率 < 80% → 跳过（CFG.filters.h2hMinRate）
- 0-0场次 > 2 → 跳过（CFG.filters.h2hMaxZeroZero）
- 无半场大小球盘口 → 跳过

**分级推荐：**
- 100% + H2H≥6 + 场均≥1.2 → 🔥🔥强烈推荐
- 80-89% + 场均≥1.8 或 (H2H≥8 + 场均≥1.5) → ✅推荐
- 其他 → ❌跳过

**加分/扣分：**
- 连胜趋势🔥 +1 | 连冷趋势❌ -1
- 初盘低估(历史场均>盘口) +0.5~1
- 团队HT场均≥0.8 +0.5 | 团队数据弱 -0.3
- 31-45'集中≥50% +0.3

**买入时机：**
- 盘口≤1.25 → ✅直接投
- 盘口≥1.5 → 数据够硬才投
- 降盘 → ✅门槛降低
- 1-10分钟进球率<10% → ⏳等降盘

## 第三部分：世界杯让球盘准备计划

### 3.1 当前局限

V38当前只分析**半场大小球**，要让球盘也需要同时分析。让球盘AH与半场大小球的差异：

| 维度 | 半场大小球（当前） | 让球盘AH（世界杯目标） |
|:----|:-----------------|:-------------------|
| 有效命中率 | ≥80%才盈利 | **≥55%即可盈利**（均赔1.85-1.95） |
| 核心依赖 | H2H进球率（历史） | **近期状态 + 实力差**（当前） |
| H2H价值 | 高（联赛战术延续） | **低**（国家队4年一轮换） |
| 市场效率 | 机构定价薄 | **高度有效市场，全球聪明钱洪流** |

### 3.2 需要增加的数据提取

Crown全指数区「全场」行已包含让球盘数据 (`parts[5]`=让球盘口)，当前代码只取了半场大小球，待扩展到同时提取：

```js

  ah: { init: -0.5, cur: -0.5 },          // 全场让球（待加）
  ahWater: { init: 0.85, cur: 0.95 }     // 让球水位（待加）

```

### 3.3 世界杯让球盘规则预设（硬编码）

```
小组赛第1轮: 深盘(≥1.25)不追，强队慢热规律
小组赛第2/3轮: 看近期状态
小组赛第3轮: 无战意比赛一律降级
淘汰赛: 倾向小球，让球盘极度谨慎
中立场+跨洲: 实力差权重打折
公众热度高(传统强队): 下盘价值
夺冠赔率倒数: 替代ELO作为实力差基准
```
