## 一、项目概述

### 1.1 一句话定义

V4 是一个**基于 API-Football 实时数据的足球半场大球走地策略系统**。核心逻辑是：赛前筛选高概率进球比赛进入候选池，赛中等待盘口自然衰减至合理区间后进场，赛后自动结算并复盘。

### 1.2 策略核心假设

足球博彩市场中存在一个结构性的定价偏差：**赛前半场大球盘口往往高估了"强队开场就能进球"的概率**。当比赛前 10 分钟未产生进球时，盘口会迅速从大 1.25/1.5 降到大 1.0/0.75，而实际进球概率的衰减速度远慢于盘口价格的下降速度。我们的策略赚取的就是这个**时间衰减溢价**。

### 1.3 与 V2 的关系

| 系统 | 策略 | 市场 | 状态 |
|:---|:---|:---|:---|
| **V2** | HT 1X2 平局错杀 | 半场胜平负 | 纸盘验证中 |
| **V4** | 半场大球走地回调 | 半场亚洲大小球 | 纸盘观察期 |
| V3 | 世界杯 Elo 套利 | 全场亚盘 | 待大赛激活 |

V4 与 V2 完全独立运行，互不干扰。V4 不做赛前投注建议，所有进场动作都在开赛后触发。

## 三、数据采集管线

### 3.1 数据源

系统通过 **API-Football Pro**（每日 7,500 次请求额度）采集以下数据：

| 数据类别 | API 端点 | 采集频率 |
|:---|:---|:---|
| 赛程 | `fixtures?date=` | 每次扫描 |
| 历史交锋 | `fixtures/headtohead?h2h=` | 逐场 |
| 进球事件 | `fixtures/events?fixture=` | 有效候选 |
| 半场赔率 | `odds?fixture=` | 赛前 + 赛中 |
| 走地赔率 | `odds/live?fixture=` | 赛中轮询 |
| 伤停 | `injuries?team=` | 每次扫描 |
| 首发阵容 | `fixtures/lineups?fixture=` | T-30分钟 |
| 赛中统计 | `fixtures/statistics?fixture=` | 赛中轮询 |
| 排名 | `standings?league=` | 每次扫描 |
| 球队赛程 | `fixtures?team=&next=3` | 每次扫描 |

### 3.2 时间窗口规则

- **H2H 时间红线**：仅采集 2020 年及之后的交锋记录。2020 年前的足球生态（疫情前战术体系、球员阵容）被视为过期噪音。
- **H2H 样本底线**：2020 年以来至少 3 场交锋才纳入分析。
- **扫描窗口**：默认扫描今天 + 明天全部白名单联赛未开赛比赛，可通过 `--lookahead-hours` 参数收窄。

### 3.3 白名单联赛

覆盖 56 个联赛：英超、西甲、德甲、意甲、法甲、英冠、德乙、荷甲、葡超、比甲、俄超、土超、瑞士超、奥甲、捷克甲、希腊超、波兰超、罗甲、丹超、瑞典超、挪超、沙特联、阿联酋超、卡塔尔联、印度超、韩K联、J联赛、澳超、美职业、墨西联、巴西甲、阿甲、玻利甲、秘鲁甲、智利甲、哥伦比亚甲、乌拉圭甲等。

## 四、赛前画像引擎

### 4.1 H2H 多维画像（h2h_engine.py）

每场通过 H2H 的比赛，系统计算以下维度：

#### 上半场（HT）
- HT 有球率：近 10 场 H2H 中上半场至少 1 球的场次比例
- 场均 HT 进球：上半场平均进球数
- 进球时间分桶：0-15分钟 / 16-30分钟 / 31-45分钟各区间有球比例

#### 下半场（SH）
- SH 有球率：下半场至少 1 球的场次比例
- 场均 SH 进球
- 进球时间分桶：46-60分钟 / 61-75分钟 / 76-90分钟

#### 全场（FT）
- FT 2+球率：全场至少 2 球的场次比例
- 场均全场进球
- 0-0 场次计数

#### 近期动能
- 主/客队近 5 场 HT 有球率
- 主/客队近 5 场 SH 有球率
- 主/客队近 5 场 FT 2+球率
- 主/客队近 5 场场均 HT/SH 进球
- HT 攻防交叉（主攻 vs 客防，客攻 vs 主防）

#### 回调适配指标
- 0-10分钟进球概率（开场闪击倾向）
- 11-30分钟进球概率（等待后前半段压力）
- 11-45分钟进球概率（走地回调后剩余出球能力）
- 16-45分钟进球概率（排除前15分钟的持续压力）
- 回调适配评级：STRONG / OK / WEAK
- Early-Only 标记：开场强但 10 分钟后弱的比赛

### 4.2 联赛基准（league_baseline.py）

每个联赛基于本赛季已完赛比赛计算 HT/SH/FT 基准，判定联赛进球环境：
- FRIENDLY（友好，HT率≥60%）
- NEUTRAL（中性）
- COLD（冷淡，HT率<50%）
- UNKNOWN（样本不足）

### 4.3 赛季阶段（season_phase.py）

- EARLY：赛季进度 < 20%，近期样本未稳定
- MID：20%-75%，正常判断
- LATE：75%-剩余3轮，需结合战意
- FINAL_ROUND：最后3轮，战意权重最高

### 4.4 战意分析（motivation.py）

基于 API-Football standings 判断：
- TITLE_RACE（争冠）/ CONTINENT_RACE（欧战资格）
- RELEGATION_RISK（保级）/ MID_TABLE_SAFE（中游安全）
- 赛季末中游安全区比赛自动降级为观察

### 4.5 赛程压力（schedule_pressure.py）

检测未来 7/10 天比赛密度，HIGH 压力比赛不进入自动监控。

### 4.6 数据覆盖闸门（api_coverage.py）

对每场比赛评估 API 数据完整度：
- FULL/GOOD → 允许进入自动走地监控
- BASIC → 仅观察
- WEAK → 跳过

## 五、策略执行流水线

### 5.1 四段式时间线

```
12:00 BJT    第1次扫描    首次建池，收集全部候选
17:00 BJT    第2次刷新    更新赔率/伤停/排名/赛程
T-30 分钟    首发复核    阵容闸门
0-15 分钟    走地进场    等待盘口衰减后执行
```

### 5.2 候选池入池标准（赛前）

满足以下条件的比赛进入 `HT_LIVE_OVER` 候选：

1. **近期 HT 攻防动能**：双方综合 ≥ 70%，或攻防交叉威胁 ≥ 65%
2. **近期时间分布**：11-45 分钟压力 ≥ 50%，且非纯 0-10 闪击型
3. **HT 走地评分** ≥ 50 分
4. **评分最强方向** 必须是 HT_LIVE_OVER
5. **半场大球盘口** ≥ 大 1.25
6. **API 数据覆盖** ≥ GOOD

### 5.3 首发阵容闸门（T-30）

开赛前 30 分钟拉取首发名单，与历史首发比对：

| 动作 | 触发条件 |
|:---|:---|
| **BOOST** | 攻击端完整 + 防线有缺口 |
| **KEEP_WATCH** | 阵容正常 |
| **WATCH_CAUTION** | 阵容一般 |
| **DROP_ATTACK_WEAK** | 攻击核心缺失 → 移出监控 |
| **DROP_HEAVY_ROTATION** | 大轮换 → 移出监控 |

### 5.4 走地进场规则（0-15分钟）

```
开赛 0-10 分钟：
  ├── 有进球 → SKIP_EARLY_GOAL
  └── 0-0 → 继续观察

8-15 分钟窗口：
  ├── 盘口降到大 1.0 或大 0.75
  ├── Over 水位在合理区间（大1.0: 1.65-2.05, 大0.75: 1.60-1.90）
  ├── 无红牌
  ├── 无重大伤退/长时间VAR
  ├── 比赛节奏不沉闷（射门/危险进攻/角球至少一项支持）
  └── → BUY_NOW（纸盘进场）

15 分钟后：
  └── 仍未达到条件 → SKIP_WINDOW_CLOSED
```

### 5.5 下半场评估（45分钟）

半场后，系统处理 SECOND_HALF_OVER 候选：

- `SH_BUY_NOW`：半场场面 + 比分结构 + 下半场盘口都支持
- `SH_WATCH`：条件接近，人工复核
- `SH_SKIP_TEMPO`：上半场沉闷或红牌
- `SH_SKIP_CONTEXT`：半场比分结构不支持

### 5.6 结算引擎

使用亚洲盘规则（不同于欧洲盘）：

| 盘口线 | 半场1球 | 半场2球 |
|:---|:---|:---|
| 大 0.75 | 半赢 | 全赢 |
| 大 1.0 | **走水**（退本金）| 全赢 |
| 大 1.25 | 半输 | 全赢 |
| 大 1.5 | 全输 | 全赢 |

## 六、三方向评分体系

系统为每场比赛同时计算三套独立分数：

| 方向 | 满分 | 用途 | 策略归属 |
|:---|:---:|:---|:---|
| **HT_LIVE_OVER** | 100 | 上半场走地回调 | 主策略，可进场 |
| **SECOND_HALF_OVER** | 100 | 下半场大球参考 | 仅观察，不进上半场池 |
| **FULLTIME_OVER** | 100 | 全场大球参考 | 仅观察 |

**核心纪律**：三套分数独立研判。下半场和全场方向分数再高，也不进入上半场走地雷达。进场方向必须与评分最强方向一致。

## 七、漏斗指标体系

### 7.1 全链路漏斗

```
赛前候选数
  ↓
进入走地监控数
  ↓  (减去：首发DROP、赛程压力HIGH、API覆盖不足)
成功等到降盘数
  ↓  (减去：降盘前进球跳过)
临场节奏合格数
  ↓  (减去：节奏沉闷、红牌、伤退)
最终纸盘进场数
  ↓
HT有球命中数
  ↓
亚洲盘结算 ROI
```

### 7.2 按维度分桶

- 不同盘口线 ROI：0.75 / 1.0 / 1.25
- 不同进场分钟 ROI：0-5 / 6-10 / 11-15
- 不同联赛独立 ROI
- 不同进场窗口（早盘 vs 午盘 vs 临场）

## 十一、风险声明

1. **纸盘模式**：当前系统处于纯纸盘验证阶段，不接入实盘资金。
2. **样本不足**：策略有效性需至少 300 场纸盘样本验证，在此之前不做实盘决策。
3. **API 依赖性**：系统完全依赖 API-Football，服务中断或数据延迟将影响所有模块。
4. **亚洲盘特殊性**：半场大小球的亚洲盘结算规则与欧洲盘不同，ROI 计算需使用专用结算模块。
5. **市场流动性**：走地盘口的价格和深度受实时市场流动性影响，历史回测不能完全模拟真实执行。

---

> 📌 **核心设计理念**：不在赛前预测谁会进球，而是在赛中等待盘口犯错。用时间换价格，用纪律换盈亏比。
