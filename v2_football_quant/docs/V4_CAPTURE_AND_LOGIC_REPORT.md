## 一、数据采集：三层 Ultra Capture

### 1.1 分层模型

```
比赛池: universe (551场白名单全量)
    ↓ 调度器分层
┌──────────┬──────────┬──────────┐
│ A_candidate │ B_shadow  │ C_slice   │
│ 入池候选    │ 未入池全量 │ 全量切片   │
│ 每2分钟采集 │ 每2分钟    │ 关键分钟    │
│ 0-20分钟    │ 0-20分钟   │ [0,5,8,10,12,15,20,45] │
└──────────┴──────────┴──────────┘
```

### 1.2 A 通道双源

| 通道 | 条件 | 当前 |
|:---|:---|:---:|
| strict_v2 | coverage≥BASIC + HT_LIVE_OVER≥55 + 0.75/1.0/1.25线存在 | 2场 |
| relaxed | best_score≥70 + coverage≥BASIC | 10场 |

### 1.3 采集端点

每个候选每 2 分钟采集 4 个维度：

| 端点 | 数据 | 用途 |
|:---|:---|:---|
| `odds/live?fixture=` | 实时盘口 | 衰减曲线校准 |
| `fixtures?id=` | 比分+状态 | 进球时机验证 |
| `fixtures/events?fixture=` | 进球事件 | 时间分桶校准 |
| `fixtures/statistics?fixture=` | 赛中统计 | 节奏判断 |

### 1.4 预算分配

```
75,000次/天 →  65,000 soft_limit → C降级 → B降频 → A保持
A优先(10,000 reserve) → 剩余给B → 剩余给C
```

| 来源 | 数据 | 采集时机 |
|:---|:---|:---|

| odds-api.io | Sbobet全场盘口 | 补充 |

### 2.2 画像维度

每场比赛计算：

```
H2H画像          → HT/SH/FT进球率 + 场均进球 + 进球时间分桶
回调适配          → STRONG / OK / WEAK (0-10/11-45分钟压力)
近期动能          → 近5场HT/SH/FT攻防交叉
联赛基准          → FRIENDLY / NEUTRAL / COLD
赛季阶段          → EARLY / MID / LATE / FINAL_ROUND
排名战意          → 保级 / 争冠 / 中游安全区
赛程压力          → 7/10天密度 HIGH/MEDIUM/LOW
首发阵容          → 攻击/中场/防守核心完整度
天气              → 温度/降雨/风速 → 边际EV调整
```

### 2.3 关键规则

| 规则 | 值 |
|:---|:---|
| H2H 时间红线 | 仅2020年及以后 |
| 样本底线 | 2020+ ≥3场 |
| 入池阈值 | HT走地分≥50 + 半场盘口≥1.25 |
| 天气边际 | 大雨-5%EV，大雨+低温+大风-12%EV |

| 方向 | 满分 | 用途 | 策略归属 |
|:---|:---:|:---|:---:|
| HT_LIVE_OVER | 100 | 上半场走地回调 | ✅ 主策略 |
| SECOND_HALF_OVER | 100 | 下半场大球参考 | 仅观察 |
| FULLTIME_OVER | 100 | 全场大球参考 | 仅观察 |

**核心纪律**：三方向互不污染。SH/FT分数再高也不进入上半场走地池。

## 四、EV 联合决策链（v3.2.1 核心）

```
赛中实时数据 (0-20分钟)
    │
    ├─ ht_goal_hazard_model.py  → P0 / P1 / P2plus
    │     剩余时间 × 历史进球率 → 条件得分概率
    │     例: 已过8分钟0-0, HT_LIVE_OVER=75 → P1=42% P2+=28%
    │
    ├─ line_decay_model.py      → market_prob / edge
    │     实时盘口 vs 衰减曲线 → 公平概率偏离度
    │     例: 0-0第10分钟, 大1.0从1.65→1.85, edge=+3.2%
    │
    ├─ asian_ev.py              → EV_gross
    │     亚洲盘特殊结算: 1球=走水(退本金) / 2球=赢全
    │     EV_gross = P(win)×0.85 + P(push)×0 + P(loss)×(-1)
    │
    ├─ execution_cost_model.py  → EV_net
    │     扣除滑点(0.02-0.05) + 流动性折扣
    │
    ├─ risk_guard.py            → PASS / BLOCK
    │     联赛COLD? 赛程HIGH? 赛季末中游?
    │
    └─ 最终决策
         EV_net > min_ev_threshold → PAPER_BUY_NOW
         否则                       → PAPER_ONLY / SKIP
```

### 4.1 min_ev_threshold 默认值

| 评级 | 阈值 | P(EV>0)门槛 |
|:---|:---:|:---:|
| **A+** | EV_net ≥ +0.08 | >65% |
| **A** | EV_net ≥ +0.05 | >58% |
| **B** | EV_net ≥ +0.02 | >52% |
| C-D | EV_net < +0.02 | SKIP |

### 4.2 动作优先级（从高到低）

```
RISK_BLOCKED     → 风险守卫拦截，绝对不进
SKIP             → 不满足任何条件
WAIT_LINE        → 盘口未降到目标线
WAIT_TEMPO       → 节奏数据未达标
PAPER_ONLY       → EV_net不足，仅纸盘记录
PAPER_BUY_NOW    → EV_net > 阈值，纸盘推荐进场
SKIP_WINDOW_CLOSED → 超过15分钟，窗口关闭
```

## 五、走地进场窗口

```
开赛 0-10分钟:
  ├─ 有进球 → SKIP_EARLY_GOAL
  └─ 0-0   → 继续观察

8-15分钟窗口:
  盘口降到大1.0或大0.75
  Over水位合理（大1.0: 1.65-2.05）
  EV_net > min_ev_threshold
  无红牌/重大伤退
  节奏不沉闷（射门/角球至少一项支持）
  天气边际未触发风险
  → PAPER_BUY_NOW

15分钟后:
  → SKIP_WINDOW_CLOSED
```
