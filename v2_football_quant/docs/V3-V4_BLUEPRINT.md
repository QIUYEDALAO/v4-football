## 二、V3 世界杯模型

### 核心特征（废弃 last_5）
- **国家队 Elo 积分**：基准胜率的唯一核心
- **全队总身价**：构建"公众认知偏差因子"（Perception Gap = Elo排名 - 身价排名）
- **主帅保守指数 (1-10)**：德尚、索斯盖特=高保守

### 三大策略
- **策略 A**：Perception Gap 极高时 → 重注受让亚盘（+1.25/+1.5）
- **策略 B**：淘汰赛双保守主帅 → 重仓全场/半场平局
- **策略 C**：小组赛第三轮默契球 → 概率强制修正

### 数据源
- Elo 积分：eloratings.net 或 fifa.com 爬取
- 身价：Transfermarkt 爬取
- 战术保守指数：人工标注 32 强

## 三、V4 五大联赛模型

### 进阶因子
- **xG Differential**：xG - 实际进球，均值回归因子
- **PPDA（高位压迫指数）**：防守强度度量
- **首发伤停折损**：核心球员权重表 + 赛前 1 分钟套利

### 赛季周期切片
- **前 8 轮（盲盒期）**：做多升班马/换帅队的主场受让
- **中段（平稳期）**：严格 xG 均值回归
- **最后 8 轮**：战意权重（保级队胜率 +10~15%）

### 临场套利
- odds_monitor.py：赛前 60 分钟每分钟轮询
- 捕捉首发名单公布瞬间的赔率错位
